# 🍔 FoodApp

A modern React-based food ordering application that allows users to browse restaurants, explore menus, and search for their favorite food items. This project was built to practice React fundamentals and modern frontend development concepts.

## ✨ Features

* 🍽️ Browse restaurants and menus
* 🔍 Search restaurants
* ⚡ Fast and responsive user interface
* 🧩 Reusable React components
* 🛣️ Client-side routing with React Router
* 📱 Responsive design
* 🎨 Styled using Tailwind CSS

## 🛠️ Tech Stack

* React 19
* React Router
* Parcel
* Tailwind CSS
* JavaScript (ES6+)
